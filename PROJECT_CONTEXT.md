# Контекст Note Paint

Актуальная база: версия **0.9.0**. Приложение работает и опубликовано: https://akhmetsagindyk.github.io/note-paint/ . Репозиторий: https://github.com/akhmetsagindyk/note-paint . Этот файл — компактная передача контекста новым чатам; поведение проверять по текущему коду.

## Замысел и предпочтения

Автор делает биты в FL Studio 26 на Mac. Начали с бесплатного аналога ретро MIDI-визуализатора, затем добавили экспериментальные аудиореактивные стили. Важны минимальный интерфейс, плавное движение с понятной связью с частотами, редактируемое оформление и отсутствие платных сервисов. Общение — по-русски, дружески.

## Технологии и карта кода

React 19.1, TypeScript 5.8, Vite 6.3, Canvas 2D, Web Audio API, @tonejs/midi 2.0.28. Backend отсутствует. pnpm-lock.yaml фиксирует зависимости; CI использует Node 24 и pnpm 11.25.0.

## Аудио и синхронизация

Один Transport для всех вкладок. Цепочка: AudioBufferSourceNode → AnalyserNode → GainNode → AudioContext.destination. Позиция опирается на AudioContext.currentTime, не на независимый таймер анимации. Есть play/pause/stop, перемотка, громкость и локальное демо. Пробел не перехватывается при редактировании полей и не повторяет переключение при удержании.

Был случай: картинка движется, даже демо без звука, другие приложения звучат. Точная причина не установлена. Добавлено «Восстановить звук»: новый Transport/AudioContext с сохранением буфера, позиции, громкости и состояния; старый освобождается после успешной замены. Пользователь подтвердил восстановление звука. Не считать конкретную причину доказанной и не удалять обход.

## Реализованные режимы и решения

### Piano roll

MIDI-ноты с учётом tempo map, дорожки и их визуальное скрытие, курсор, масштаб времени, перемотка и сдвиг MIDI ±60 с. Сетка по начальному BPM условная при переменном темпе. WAV/MP3 содержит готовый звук; MIDI не воспроизводит плагины. Лимиты: 150 МБ аудио, 5 МБ MIDI, 30 000 нот. Pitch bend, FL slides и sustain не визуализируются.

### Signal atlas

Поле точек, зернистая полоса, осциллограмма/спектр и фазовый компас. Низ даёт крупные изгибы, середина деформирует поле, верх добавляет мелкие движения/плотность. Сглаженный Drift, чувствительность 0.2–4×; при воспроизведении есть базовое движение без баса, на паузе оно замирает.

Пробовали Pulse: пользователь отверг резкость и зависимость от баса. **Pulse удалён**, оставлен Drift с чувствительностью.

Редактор: фон сцены и рисунка, цвета сигнала/линий/деталей, ширина/высота, скругление, размер точек, надписи и сброс. Изменения не перезапускают звук.

### Memory bloom

Глаз нарисован процедурно: дезеринг, шум, веки, радужка, зрачок и ресницы. По последней просьбе убраны звезда и весь текст внутри постера; остались глаз, горизонтальные полосы и нижние штрихи.

Веки по умолчанию реагируют на **2500–12000 Гц, 2×**, зрачок сужается от **30–200 Гц, 1×**. Для каждого диапазона доступны границы 20–16000 Гц, усиление 0.25–8× и пресеты. Это управление визуализацией, а не EQ звука. Анализ использует линейные амплитуды из FFT dB. Индикаторы отражают обработанное движение, не абсолютную громкость.

Попытка открывать веки от общей громкости не устроила автора: казалось, что ими управляет бас. Восстановлены независимые диапазоны; не возвращать RMS всего микса как источник век. У инструментов бывают гармоники в разных диапазонах — полосы не выделяют инструменты.

Адаптивный фон следует за недавним уровнем: новые подъёмы вызывают реакцию, постоянный сигнал перестаёт держать глаз открытым. Крутилка «Возврат» 0.15–2.5 с управляет затуханием век и зрачка, атака сглажена. На паузе кадр заморожен; после перемотки/смены вкладки реакция рассчитывается заново.

Редактор меняет цвета сцены/карточки/полос/глаза/зерна, ширину, высоту и скругление. Прежний чёрный фон заменён на редактируемый светлый. Рисунок масштабируется и обрезается по форме карточки.

### Dream room

Dreamcore/liminal-сцены с рамкой, стрелкой, тематической подписью и зерном. Три оригинальные AI-фотосцены включены в проект; runtime-генерации, внешнего поиска фото и текстового API нет. Свои JPG/PNG/WebP: до 12 по 15 МБ, тип небо/лестницы/переходы задаётся вручную. Можно отключить встроенные сцены, когда добавлены свои.

EN/RU-подписи выбираются из тематических наборов; собственные строки заменяют набор. Seed задаёт перемешивание, композицию и фразы; соседние фото не повторяются при наличии выбора. «Новая серия» меняет seed, «Следующий кадр» даёт ручной сдвиг.

Декодированное аудио один раз сканируется: mono, фильтрация 30–180 Гц, RMS окна около 10 мс, адаптивный фон, поиск нарастаний и защита от частых повторов. Это приближение к кику: бас тоже срабатывает. Смена на каждую/2/4/8 атаку, чувствительность 0.4–3, минимальный интервал 0.25–3 с имеет приоритет. Без атак автоматической смены нет.

Смены предвычислены; поиск кадра по позиции бинарный, поэтому перемотка при тех же настройках и ручном сдвиге воспроизводит ту же последовательность. Анализ пока на главном потоке и может задержать UI на длинном файле. Экспорт PNG 900×1200 сохраняет только композицию после загрузки изображений.

## Состояние, приватность и публикация

- localStorage: `note-paint-atlas-design`, `note-paint-bloom-design`, `note-paint-eye-bands`.
- Аудио/MIDI, свои фото и настройки Dream room живут в сеансе. Фото используют object URL, переживают смену вкладки, освобождаются при удалении/размонтировании; после перезагрузки импорт повторяется.
- Пользовательские файлы не загружаются на сервер. Публичны код и встроенные сцены. Секреты и личные медиа не добавлять в git.
- `.github/workflows/pages.yml`: push main → установка по lockfile → тесты → build → GitHub Pages. `dist/` не коммитится.
- `vite.config.ts` использует `base: './'`; сцены строят пути через `import.meta.env.BASE_URL`. Абсолютный `/scenes/...` сломает размещение в подпапке.

## Дальше — не реализовано

Экспорт видео **отложен самим пользователем** ради экспериментов со стилями. Сохранение полной сессии также отсутствует. Возможные будущие задачи, требующие выбора автора: постоянная библиотека/настройки Dream room, больше сцен и подписей, улучшение детектора атак и перенос анализа в worker, видеоэкспорт. Это идеи, а не текущие поручения или обещания.
