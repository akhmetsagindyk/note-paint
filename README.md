# Note Paint

Бесплатный браузерный визуализатор битов. [Открыть сайт](https://akhmetsagindyk.github.io/note-paint/) · [Исходники](https://github.com/akhmetsagindyk/note-paint)

React + TypeScript, Canvas 2D, Web Audio API и @tonejs/midi. Без сервера и платных API: музыка и собственные фото обрабатываются в браузере, не отправляются на GitHub. Текущая версия — **0.9.0**.

## Четыре вкладки

- **Piano roll** — MIDI-ноты в стиле Windows 95/98, курсор, дорожки, масштаб и сдвиг MIDI относительно аудио (±60 с).
- **Signal atlas** — плавный дрейф точек и полос от низких, средних и высоких частот. Чувствительность и редактор цветов, размеров, скругления, точек и надписей.
- **Memory bloom** — процедурный глаз и полосы. Веки открываются от выбранных высоких частот, зрачок сужается от низких. Отдельные диапазоны, усиления, возврат и редактор оформления.
- **Dream room** — dreamcore-открытки: фото, рамка, стрелка, тематическая фраза и зерно. Смена по низкочастотным атакам, свои фото и подписи, сохранение PNG 900×1200.

Загрузи WAV/MP3 или нажми **«Запустить демо»**. MIDI нужен только для Piano roll; он не содержит звук инструментов. **Пробел** — играть/пауза (кроме редактирования полей). Звук и позиция общие для всех вкладок. Если анимация идёт без звука, попробуй **«Восстановить звук»**, проверь громкость и заглушение вкладки.

## Запуск на Mac

Установи Node.js 24 и pnpm 11.25.0. Открой корень проекта в Терминале:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открой адрес из Терминала (обычно http://127.0.0.1:5173). Остановка — Control+C; повторный запуск — `pnpm dev`. После установки зависимостей локальное приложение работает без интернета. Для использования опубликованного сайта устанавливать Node.js не нужно.

```sh
pnpm test         # проверки логики
pnpm build        # TypeScript + production-сборка в dist/
pnpm preview      # просмотр сборки локально
```

## Файлы из FL Studio 26

1. В исходном проекте включи Song mode и экспортируй полный бит с начала: **File → Export → Wave file** (или MP3). Убери случайное выделение участка Playlist.
2. Для MIDI всей песни сначала сохрани **отдельную копию .flp**. Только в копии: **Tools → Macros → Prepare for MIDI export**, затем **File → Export → MIDI file**, с того же начала в Song mode. Макрос заменяет инструменты на MIDI Out — оригинал нужен для дальнейшей работы со звуком.
3. Для одного паттерна: меню Piano roll → **File → Export as MIDI file**. Если паттерн начинается позже в песне, настрой сдвиг MIDI в приложении.

MIDI не переносит плагины, эффекты, аудиоклипы и вокал. Для готового звучания нужен WAV/MP3. Время нот учитывает tempo map, но сетка использует начальный BPM и не является точной тактовой разметкой при смене темпа. FL slides, pitch bend и sustain пока не визуализируются.

## Хранение и ограничения

- Аудио до 150 МБ, MIDI до 5 МБ и 30 000 нот. Декодированный звук требует дополнительной памяти.
- Оформление Atlas/Bloom и частотные диапазоны глаза сохраняются в localStorage этого адреса. Файлы и настройки Dream room после перезагрузки выбираются заново.
- В Dream room встроены три оригинальные AI-сцены; во время работы генератор и поиск фото не вызываются. Можно добавить до 12 JPG/PNG/WebP по 15 МБ; тип сцены выбирается вручную.
- Детектор Dream room ищет атаки 30–180 Гц: бас тоже может переключать кадры. Это не выделение кика из микса. Длинное аудио может ненадолго задержать интерфейс при анализе.
- Экспорт видео и сохранение полной сессии пока не реализованы. Видео отложено по желанию автора.

## Разработка и публикация

Для нового чата сначала прочитай [AGENTS.md](AGENTS.md) и [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md): там карта кода, решения и ограничения.

Push в `main` запускает `.github/workflows/pages.yml`: Node 24, pnpm 11.25.0, установка по lockfile, тесты, сборка и публикация `dist/` на GitHub Pages. Источник Pages — GitHub Actions. Относительная база Vite и пути сцен через `BASE_URL` обеспечивают работу по адресу `/note-paint/`.
