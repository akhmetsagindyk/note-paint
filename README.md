# Note Paint

Бесплатный браузерный визуализатор битов: React + TypeScript, Canvas 2D, Web Audio API и @tonejs/midi. Никаких аккаунтов, загрузок музыки на сервер или платных API. После установки зависимостей интернет не нужен.

## Открыть сайт

[Note Paint — онлайн](https://akhmetsagindyk.github.io/note-paint/)

Аудио и собственные фото обрабатываются в браузере. Они не загружаются на GitHub или сервер. Код и три встроенные AI-сцены опубликованы в репозитории. Для использования сайта Node.js и установка приложения не нужны.

## Публикация

Сайт публикуется через GitHub Pages. Изменения в `main` запускают `.github/workflows/pages.yml`: установка зависимостей из lockfile, тесты, сборка и публикация `dist`. В Settings → Pages источником должен быть GitHub Actions. Локальный запуск по инструкции ниже остаётся доступен.

## Версия 0.9 — Dream room и редактор Signal atlas

### Signal atlas

В редакторе справа меняются внешний фон, фон рисунка, цвет точек/сигнала, рамок и деталей. Есть ширина, высота, скругление, размер точек и выключение надписей. Изменения не перезапускают звук. Оформление сохраняется локально в браузере, кнопка сброса возвращает исходное.

### Dream room

Четвёртая вкладка создаёт dreamcore-открытки: фотографическая сцена, рамка, стрелка и фраза.

1. Нажми «Запустить демо» или загрузи свой WAV/MP3.
2. Аудио один раз разбирается на низкие атаки (30–180 Гц). Счётчик показывает найденные атаки и смены. Это приближение к кикам: инструмент не выделяется из микса, бас тоже может сработать.
3. Выбери смену на каждый / 2-й / 4-й / 8-й удар, чувствительность детектора и минимальную паузу между кадрами (0.25–3 с). Минимальная пауза имеет приоритет. Если атак нет, автоматической смены нет.
4. «Следующий кадр» работает вручную и без музыки; «Новая серия» меняет порядок фото, раскладку рамок и выбор фраз. При тех же настройках и ручном сдвиге перемотка возвращает ту же последовательность — здесь нет случайного таймера.
5. «Сохранить PNG» сохраняет только открытку, без интерфейса, 900×1200 px. Сохранение доступно после загрузки изображений. Экспорт видео по-прежнему отложен.

**Фото:** встроены три оригинальные AI-сцены, созданные для этого проекта: небо, лестница, пустой коридор. Во время работы приложение не обращается к генератору изображений и не скачивает фото из интернета. Можно добавить до 12 своих JPG/PNG/WebP по 15 МБ, отключить встроенный набор, назначить каждому тип «Небо / Лестницы / Переходы» и удалить свои фото. Автоматического распознавания содержания нет — тип выбирается вручную. Файлы остаются локально и очищаются при перезагрузке; это первая версия библиотеки.

**Фразы:** английский/русский, связанные наборы для неба/света, пути/возвращения и памяти/знакомых мест. «По типу фото» использует назначенный тип сцены. Можно задать свои строки (по одной на строку): они заменяют встроенный набор. Это детерминированный выбор из тематической коллекции, без платного текстового API. Доступны цвет рамки/стрелки/текста и зерно.

Настройки Dream room и свои фото пока живут в текущем сеансе. После перезагрузки их нужно выбрать заново. Длинные файлы могут потребовать несколько секунд для анализа. Анализ не меняет звук. На паузе изображение замирает.

## Восстановление аудиовыхода

Если визуализация движется, а звука нет, попробуй кнопку **«Восстановить звук»** рядом с демо. Она создаёт новый AudioContext и аудиосоединения, сохраняя загруженный файл, позицию и текущую громкость. Если была пауза — нажми «Играть». Это помогает проверить сбой аудиовыхода страницы после прерывания или смены устройства; не гарантирует устранение любой причины тишины.

Также проверь, что вкладка Safari не заглушена и нужное устройство вывода выбрано на Mac. После обычного обновления страницы WAV/MP3 нужно выбрать заново — файл не сохраняется в браузере.

## Версия 0.8 — только глаз и полосы

Из Memory bloom убраны звезда и все надписи. Остались глаз, горизонтальные полосы спектра и нижние штрихи. Композиция пересобрана без пустого места от заголовка. Настройки реакции, возврата и редактор сохранены; цвет «Полосы» меняет оба вида полос.

## Частоты движения

В Memory bloom у век и зрачка теперь независимые диапазоны анализа. Это не эквалайзер аудио: звук не меняется, настраивается только движение.

**По умолчанию:** веки реагируют на верх 2500–12000 Гц (усиление 2×), зрачок сужается от низа 30–200 Гц (1×). Общая громкость больше не используется как источник открытия век.

В панели «Частоты движения»:

- Спектр показывает распределение звука. Золотая зона — диапазон век, зелёная — зрачка. Перекрытие зон допустимо: тогда звук в пересечении может влиять на оба движения.
- Для каждой части есть «От / До» в герцах, логарифмические ползунки, отдельное усиление 0.25–8× и кнопки «Низ / Середина / Верх».
- Процентные индикаторы показывают силу **движения после адаптации и сглаживания**, а не абсолютную громкость частот. После окончания звука они могут ещё некоторое время затухать согласно «Возврату».
- «Вернуть верх / низ» возвращает исходную связь. Диапазоны и их усиления сохраняются в этом браузере для этого адреса.

Если веки почти не открываются: посмотри на спектр в золотой зоне, увеличь усиление именно век; для более мягкой мелодии попробуй диапазон 1000–6000 Гц. Это уже захватывает часть середины. Низ и верх — диапазоны звука, а не отдельные инструменты: у бочки могут быть высокочастотный щелчок и гармоники, у мелодии — низкие ноты.

## Возврат и редактор Memory bloom

Третья вкладка — редактируемый постер с процедурным глазом. Это Canvas-графика, а не статичная картинка.

- **Открытие глаз** следует за изменениями в выбранном диапазоне век, а не за громкостью всего трека.
- **Адаптация к треку**: недавний уровень становится фоном; новые подъёмы открывают глаз. Постоянный громкий сигнал больше не держит его полностью открытым. После смены уровня фон подстраивается примерно за несколько секунд.
- **Диапазон зрачка** (по умолчанию 30–200 Гц) управляет его сужением, тоже с учётом недавнего уровня. После затихания зрачок увеличивается.
- **Крутилка «Возврат» 0.15–2.5 с** управляет затуханием обоих движений. Тяни круг вверх/вниз, используй соседний ползунок или стрелки клавиатуры. Значение приблизительно соответствует времени ухода на 95% к исходному состоянию после прекращения реакции. Для начала попробуй 0.5–0.9 с.
- **Чувствительность** регулирует силу реакции. На паузе кадр замирает.

### Редактор

Справа в «Редакторе» меняются ширина, высота и скругление карточки; цвета фона, карточки, текста и фигур, подложки глаза, глаза и зерна. Рисунок масштабируется вместе с карточкой; ширина/высота меняют и пропорции рисунка. Зёрна и линии ограничены формой карточки. Чёрная подложка удалена, фон настраивается отдельно.

Оформление автоматически сохраняется в этом браузере для этого адреса. Кнопка «Сбросить оформление» возвращает исходную палитру и форму. Аудиофайлы, чувствительность и время возврата после перезагрузки нужно настроить заново. Если браузер запрещает локальное хранилище, оформление действует до перезагрузки.

Звук и позиция общие со всеми вкладками. MIDI для глаза не нужен; громкость прослушивания не влияет на анализ. После перемотки/смены вкладки расчёт реакции начинается заново.

## Signal atlas — плавный Дрейф

Piano roll показывает MIDI-ноты, Signal atlas — частотную графику. Звук и позиция общие, пробел — играть/пауза. Для Signal atlas нужен только WAV/MP3.

В Signal atlas оставлен один плавный режим. Ползунок **«Чувствительность» (0.2–4×)** усиливает реакцию на все диапазоны:

- Низ добавляет объём и крупные изгибы.
- Середина изгибает поле точек и сдвигает рисунок правой полосы.
- Верх добавляет мелкие движения и меняет плотность/яркость рисунка.

Плавное фоновое движение сохраняется во время воспроизведения даже без баса. Изменения от звука сглаживаются; после затихания они постепенно ослабевают. На паузе движение останавливается. Чувствительность можно менять без перезапуска анимации. Начни с 1×, затем попробуй 1.5–2×.

Если предыдущая версия уже запущена, останови её через Control+C и выполни `npm run dev` в обновлённой папке. Зависимости не менялись.

## Запуск на Mac

1. Установи Node.js **24 LTS** с https://nodejs.org (если его ещё нет). Закрой и снова открой Терминал.
2. Открой папку `note-paint` в Терминале. Можно набрать `cd ` с пробелом, перетащить папку из Finder в окно Терминала и нажать Enter.
3. Выполни:

```sh
npm install
npm run dev
```

Открой адрес, который напечатает Терминал, обычно http://127.0.0.1:5173. Терминал оставь открытым. Для остановки — Control+C. Повторный запуск: только `npm run dev`. Если порт занят, Vite выберет следующий — смотри фактический адрес.

Для первой пробы нажми **«Запустить демо»**: появится звук и пойдут ноты. Демо синтезируется локально, скачивать музыку не нужно.

## Как подготовить файлы в FL Studio 26

### Аудио

Сначала в обычном проекте выбери **Song mode**, убери случайное выделение участка в Playlist и экспортируй полный бит с начала: **File → Export → Wave file** (или MP3). WAV удобнее для точной синхронизации. Это звук всех твоих инструментов и эффектов.

### MIDI всего проекта

1. Сохрани оригинальный `.flp`, затем сделай отдельную копию через **File → Save as**, например `beat-midi-copy.flp`.
2. Только в этой копии выбери **Tools → Macros → Prepare for MIDI export**. Макрос заменяет инструменты на MIDI Out — это реальное изменение проекта. Оригинальный `.flp` оставь с исходными инструментами.
3. Выбери **File → Export → MIDI file**, экспортируй полную песню в Song mode, с того же начала, что и WAV.
4. Для продолжения работы со звуком вернись к исходному `.flp`.

Быстрый тест одной мелодии: открой её Piano roll → меню Piano roll → **File → Export as MIDI file…**. Такой MIDI относится к одному паттерну: если в песне он начинается позже, понадобится сдвиг в визуализаторе.

MIDI содержит ноты и темп, но не звук плагинов. Аудиоклипы, записанный вокал и лупы не превращаются автоматически в MIDI-ноты. FL slides, pitch bend и педаль sustain в этом MVP не визуализируются; отображаются длительности note-on/note-off. Для готового звучания всегда нужен WAV/MP3.

Официальная справка Image-Line:
- https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/fformats_save_export.htm
- https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/menu_tools.htm
- https://cluster.image-line.com/fl-studio-learning/fl-studio-online-manual/html/pianoroll_menu.htm

## Как пользоваться

- **01 / Аудио** — WAV или MP3. **02 / Ноты** — `.mid` или `.midi`. Загрузить можно в любом порядке.
- **Играть / Пауза / Стоп** управляют звуком и курсором. Щелчок по piano roll или нижний ползунок перематывает.
- **Сдвиг MIDI**: `+1.00` означает, что MIDI начинается на секунду позже аудио. `-1.00` — раньше. Диапазон ±60 секунд.
- **На экране** меняет масштаб времени. Регистр подстраивается под весь MIDI.
- Галочки скрывают дорожки визуально; готовый аудиомикс остаётся тем же.
- Цвета назначаются по дорожкам; меню помощи объясняет основные действия.
- MIDI tempo map применяется к времени нот. Тонкая сетка условная: использует начальный BPM, линейка подписана в секундах; при переменном темпе она не служит точной тактовой разметкой.

Если ноты расходятся всё сильнее со временем, проверь одинаковые темп и аранжировку при экспорте. Если постоянно запаздывают на одну величину — настрой сдвиг. Самый простой старт: WAV + MIDI всей песни от нулевой позиции.

## Ограничения версии 0.9

Экспорт видео пока не реализован. Сейчас это проигрыватель и визуализатор; следующим этапом можно добавить Canvas capture + аудиодорожку, затем стабильный MP4-рендер через FFmpeg. Не поддерживаются редактирование нот и сохранение сессии. После перезагрузки файлы нужно выбрать заново. Максимум 150 МБ аудио, 5 МБ MIDI и 30 000 нот; декодированный звук занимает больше памяти, чем исходный файл. Очень длинные треки лучше проверять частями.

## Для разработки

```sh
npm run build
npm test
npm run preview
```

`src/music.ts` — импорт и аудиотранспорт; `src/Roll.tsx` — piano roll, `src/Atlas.tsx` — аудиореактивная графика, `src/drift.ts` — сглаживание реакции; `src/main.tsx` — интерфейс; `src/style.css` — ретротема. Проверки MIDI покрывают ноты нескольких дорожек, смену темпа и некорректные/пустые файлы. `pnpm-lock.yaml` фиксирует проверенные зависимости для pnpm; npm использует версии из package.json.
