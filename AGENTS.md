# Работа с Note Paint

## Перед изменениями

- Прочитай README.md и PROJECT_CONTEXT.md, затем проверь текущие файлы и `git status`. Документация — ориентир; фактическое поведение сверяй с кодом.
- Этот каталог — корень приложения и git-репозитория. Не путай его с родительским рабочим каталогом Codex.
- Общайся с пользователем по-русски, дружелюбно и понятно. Интерфейс должен оставаться минималистичным.
- Выполняй текущий запрос; список идей в контексте не означает поручение реализовать их все.

## Что сохранять

- Бесплатная локальная обработка, без обязательного сервера, аккаунта и платных API. Не отправляй музыку и фото пользователя наружу.
- Общий аудиотранспорт и позиция всех четырёх вкладок; пробел для play/pause с исключением полей ввода.
- Atlas: плавный Drift с чувствительностью; режим Pulse удалён по просьбе пользователя.
- Bloom: только глаз и полосы, без звезды и текстов внутри композиции. Веки и зрачок имеют независимые частотные диапазоны. Не заменяй верх общей громкостью.
- Сглаживание, адаптация и возврат глаза нужны, чтобы он не дёргался и не оставался постоянно открытым.
- Сохраняй восстановление аудиовыхода и регрессионные проверки транспорта.
- Экспорт видео отложен. Не добавляй его без запроса.
- Встроенные сцены уже созданы: не заменяй и не генерируй заново без необходимости.

## Проверки и изменения

- Установка: `pnpm install --frozen-lockfile`; запуск: `pnpm dev`.
- Для изменений логики: `pnpm test`; для изменений приложения: `pnpm build`. Если tsx CLI ограничен средой, используй `node --import tsx --test tests/*.test.ts`.
- Для Canvas/UI проверяй нужные вкладки, паузу/перемотку и размеры окна визуально, когда это доступно. Не утверждай, что слышал звук, без проверки.
- Для чисто текстовых правок достаточно проверки содержания, `git diff --check` и состава diff; рабочий код не меняй попутно.
- Не стирай чужие незакоммиченные изменения. Добавляй в commit только относящиеся к задаче файлы.
- При существенном изменении поведения обновляй PROJECT_CONTEXT.md и пользовательскую инструкцию по необходимости.

## Публикация и приватность

- Репозиторий публичный. Не коммить токены, .env, локальные пути/данные авторизации, личные биты/фото, node_modules или dist.
- PROJECT_STATE.md — старый локальный игнорируемый файл; публичный источник контекста — PROJECT_CONTEXT.md. Не публикуй старый файл автоматически.
- Используй существующие способы авторизации, не записывай секреты в документацию или логи.
- Push в main автоматически публикует сайт через GitHub Actions. Commit/push выполняй в рамках запроса пользователя.
- Сохраняй `base: './'` в Vite и пути сцен через `import.meta.env.BASE_URL`: сайт размещён в подпапке `/note-paint/`.
